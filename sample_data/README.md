# Synthetic test files

All files in this directory are fictional and intended only for testing Financial AI Agent.

- `synthetic_financial_statements_2025.pdf`: formatted three-statement sample.
- `synthetic_credit_application_summary.docx`: sample application narrative and financial table.
- `synthetic_financial_test_pack.xlsx`: formula-driven financial statements, transactions, and checks.
- `synthetic_bank_statement.csv`: transaction-level bank statement fixture.
- `synthetic_payslip.txt`: payslip classification/extraction fixture.
- `synthetic_credit_policy.md`: knowledge-base ingestion and citation fixture.

The `qa_*.png` images and `*.inspect.ndjson` file are generated QA intermediates and do not need to be uploaded to Frappe.
